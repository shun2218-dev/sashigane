# 実験: 色覚特性のもとで識別色が区別できるか

実施日: 2026-08-23
関連: [decisions.md 決定5-8](../decisions.md) / [Issue #18](https://github.com/shun2218-dev/sashigane/issues/18)

## なぜ実験したか

原則5 は WCAG 適合を「後から検査して直すもの」ではなく
「そうなっているもの」にすると宣言している。

**コントラストについてはそれを実現した**（全360色相で構造的に保証、CI で検査）。
**色覚特性については何も保証していなかった。** 宣言と実態が食い違っていた。

決定5-5 は識別色を色相環に等間隔で配る。**明度も彩度も全系列で同じ**なので、
違いは色相しかない。二色覚では色相軸が潰れる。

## 方法

Machado, Oliveira, Fernandes (2009) の線形 RGB 変換行列（severity 1.0）で
1型（protanopia）・2型（deuteranopia）・3型（tritanopia）をシミュレートし、
変換後の色を OKLab に移して**最も近い2色のユークリッド距離**を測った。

### 変換の妥当性を先に確かめた

行列を記憶で書いているので、既知の挙動と照合した。

| 組み合わせ | 通常 | 変換後 |
|---|---|---|
| 赤 vs 緑 | ΔE 0.415 | **2型で 0.086**（接近する） |
| 青 vs 黄 | ΔE 0.489 | **3型で 0.323**（接近する） |
| 赤 vs 青 | ΔE 0.430 | 2型で 0.362（残る） |

赤と緑が接近し、赤と青が残るのは二色覚の既知の性質と一致する。

---

## 結果1: 現行設計は明確に不合格だった

識別色5系列（全系列が段400）の最小 ΔE、全120色相での最悪値:

| 色覚 | 最小 ΔE |
|---|---|
| 通常 | 0.079 |
| 1型 | 0.035 |
| **2型** | **0.003** |
| 3型 | 0.019 |

primary = 260°（青）のときの2型色覚下:

```
#6081c6 #7b85a1 #96894d #968841 #808593
                 ↑ 系列3   ↑ 系列4  ← ほぼ同一
```

**ΔE 0.003 は実質的に同じ色である。**

## 結果2: 較正 — 何を目標にすべきか

「0.003 は悪い」と言うには基準が要る。既知のパレットを同じ指標で測った。

| パレット | 通常 | 1型 | 2型 | 3型 | **最小** |
|---|---|---|---|---|---|
| **Okabe-Ito 5色**（色覚配慮設計の定番） | 0.156 | 0.114 | 0.110 | 0.086 | **0.086** |
| Okabe-Ito 8色 | 0.156 | 0.096 | 0.076 | 0.085 | 0.076 |
| shadcn chart-1..5 | 0.079 | 0.075 | 0.047 | 0.079 | 0.047 |
| Tailwind 500 を5色 | 0.163 | 0.042 | 0.009 | 0.107 | 0.009 |
| **sashigane 現行** | 0.079 | 0.035 | **0.003** | 0.019 | **0.003** |

**Okabe-Ito の 0.086 を目標の基準にする。**
Tailwind の 500 を並べただけのものが 0.009 で、これは実際に
チャートの系列色として使うと2型色覚下で判別できない。

## 結果3: 段をずらすと解決する

明度が同じなのが原因なので、系列ごとに段を変えた。

| 割り当て | 通常 | 1型 | 2型 | 3型 |
|---|---|---|---|---|
| 現行（全系列 段400） | 0.079 | 0.035 | 0.003 | 0.019 |
| 段 400〜800 を順に | 0.086 | 0.029 | 0.065 | 0.056 |
| 段 300〜700 を順に | 0.092 | 0.024 | 0.065 | 0.059 |
| 一段飛ばし 400,600,800,500,700 | 0.131 | **0.006** | 0.063 | 0.070 |

2型は大きく改善するが、**1型が 0.029 と伸びない。**
段300 は明色の面に対して 2.24:1 しかなく、マークに必要な 3:1 を割る。

## 結果4: 割り当て順を最適化すると Okabe-Ito 並になる

段の集合は同じまま、**どの系列にどの段を割り当てるか**を全120通り試した。

```
固定順 400,500,600,700,800 の最悪値 : 0.0289
色相ごとに最適化した場合の最悪値     : 0.0838
```

**2.9倍。** Okabe-Ito の 0.086 とほぼ同等。

暗色モード（段 100〜500）も同様に測った。

| | 最悪 ΔE | 最小コントラスト |
|---|---|---|
| 明色モード（段 400〜800） | 0.0846 | 3:1 を満たす |
| 暗色モード（段 100〜500） | **0.1095** | 3.30:1 |

暗色モードは Okabe-Ito を上回る。

### 探索コスト

120通りの評価で **0.5ms**。パレット生成本体が約22ms なので無視できる。

**探索であって恣意ではない。** 同じ入力からは必ず同じ結果が出る。

---

## 結果5: status は色だけでは解けない

自己レビューで「識別色は測ったが status を測っていない」ことに気づき、測った。

| 対象 | 最小 ΔE |
|---|---|
| 識別色（対処前） | 0.003 |
| **status 4色** | **0.0077** |

識別色より悪い。primary = 260° の2型色覚下:

```
通常   #f7004d #c26f00 #009f63 #008ed6
2型   #9b8d45 #9c8b01 #8e8767 #5080d5
       ↑danger ↑warning ↑success   ← 3色がほぼ同一
```

**danger と warning と success を取り違える。** 意味が反転する。

### 段をずらしても届かない

識別色と同じ手（系列ごとに段を変える）を試した。文字なので 4.5:1 を満たす段に限る。

| 割り当て | 最悪 ΔE | 最小コントラスト |
|---|---|---|
| 段 500 で揃える（現行） | 0.0077 | 4.50 |
| 段 500,600,700,800 を最適配置 | 0.0652 | 4.50 |
| 段 500,600,700,900 を最適配置 | 0.0685 | 4.50 |

**8.5倍改善するが、目標 0.08 には届かない。**

### なぜ届かないか

`danger` 25° と `warning` 70° は赤と黄で、**1型・2型色覚で最も潰れやすい組み合わせ**である。
色相を離せば潰れなくなるが、**それは意味を壊す**（決定5-4: 色の意味は文化的に固定されている）。

**色だけでは解けない。**

### したがって、色以外の手がかりを必須にする

WCAG 1.4.1（Use of Color）は
「色が情報を伝える唯一の視覚的手段であってはならない」と要求している。

status については**これが本来の解**であり、
色の識別性を上げることは補助にしかならない。決定5-9 として記録した。

**status の段をずらす案は採らない。** 0.065 に上げても
「色だけで判別できる」水準には届かず、
一方で status ごとに明度が違うことの見た目の代償は実際に発生する。
**届かない改善のために一貫性を捨てない。**

## 結論

| 問い | 答え |
|---|---|
| 現行設計は色覚特性下で成立するか | **しない。** 2型で最小 ΔE 0.003 |
| 原因は何か | 明度も彩度も同じで、違いが色相しかない |
| 段をずらせば直るか | **直る。** 2型 0.003 → 0.065 |
| どこまで良くできるか | 割り当てを最適化して **0.084**。Okabe-Ito の 0.086 とほぼ同等 |
| コストは | 0.5ms。無視できる |
| 目標値はいくつにすべきか | **0.08**（Okabe-Ito の実測 0.086 を基準に） |

決定5-8 として `docs/decisions.md` に反映し、全360色相の不変条件テストに入れた。

## この実験が見つけられないこと

- **弱度の色覚特性**（severity 1.0 のみを測っている）
- **実際の利用者にとって見分けやすいか。** ΔE は代理指標であって体験ではない
- **チャート以外の文脈**（隣接して並ぶか、離れているかで必要な差は変わる）
- 色以外の手がかり（マーカー形状、パターン、直接ラベル）との併用効果。
  **トークン層の外にある対処であり、これが最も効果的である可能性は高い**
