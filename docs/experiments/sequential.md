# 実験: 連続値の色帯に色相を回すべきか

実施日: 2026-08-24
対象: `packages/tokens` の生成器（全36色相 × 二色覚3種）
関連: [decisions.md 決定5-11](../decisions.md) / [Issue #36](https://github.com/shun2218-dev/sashigane/issues/36)

## なぜ実験したか

連続帯（sequential）を離散系列（categorical）とは別の役割として持つと決めたあと、
**段の作り方**で2案あった。

| 案 | 内容 |
|---|---|
| 多色相 | 明度を単調に動かしつつ、色相も primary から一定量回す（viridis 相当） |
| 単一色相 | primary の色相のまま明度だけ動かす |

多色相を推した根拠はこうだった。

> 値の大小が**明度と色相の両方**で読めるので、二色覚でも順序が崩れない。
> 「色相だけに頼らない」は決定5-8 で既に採っている判断で、その延長になる。

**この根拠は測ったら成り立たなかった。**

## 測ったもの

明度は既存の11段（`lightnesses`）をそのまま使い、色相を
`H_i = primaryH + dir × rotation × i/10` で回した帯を作る。彩度は各段で
その明度・色相の安全な最大値（`maxSafeChroma`）。

全36色相（10°刻み）の primary について、次を測った。

1. **隣接段の知覚距離** — 通常と二色覚3種すべてで最小のもの
2. **知覚明度の単調性** — 二色覚を通したあとの OKLab の L が単調に動くか
3. **status 帯との重なり** — 帯の段が status 色相の ±18° に入る数（決定5-5 の禁止帯）

## 結果1: 隣接段の弁別は、回しても良くならない

```
rot  dir  最悪隣接ΔE  最悪両端ΔE  status重なり(最大/平均段数)
  0    ±      0.0499      0.7776         11      1.5
 45    +      0.0422      0.7675          9      3.4
 45    -      0.0496      0.7734          9      3.6
 90    +      0.0361      0.7670          8      3.8
 90    -      0.0479      0.7672          8      3.9
120    +      0.0178      0.7670          6      3.7
180    +      0.0070      0.7670          6      3.9
```

**回さない（0°）が最良。** 両端の距離も回すとわずかに縮む。
彩度が sRGB の範囲で頭打ちになるため、帯全体の色差は明度が支配しているからである。

status 帯との重なりは、回すと 1.5 段 → 3.4〜4.2 段に増えた。
**連続帯の途中が「危険」「成功」の色と重なる**ことになる。

## 結果2: 回すと二色覚下で順序が反転する — これが決定打

```
rot dir  単調でない色相の数/36  最小の段差(知覚L)
  0   ±                   0           0.0467
 45   +                   0           0.0079
 45   -                   1          -0.0168
 90   +                   2          -0.0185
 90   -                   4          -0.0642
120   +                   3          -0.0296
180   -                   4          -0.0591
```

単一色相なら全36色相・全視覚型で単調（最小段差 +0.047）。
**90° 回すと4色相で順序が逆転する。**

連続帯の目的は順序が読めることなので、これは目的そのものを壊す。

### なぜ viridis は成立するのか

viridis は**明度と色相を同時に最適化して作られている。**
我々の案は「既存の明度11段はそのままに、色相だけを後から回す」形だった。
**同じ見た目の系統に属していても、作り方が違えば性質は受け継がれない。**

決定5-8 の「色相だけに頼らない」は、**離散色を見分ける**問題の答えである。
連続帯の問いは「順序が読めるか」であり、別の問いだった。
**尺度を借りてきて、問いが同じだと思い込んでいた**（教訓2）。

## 採った案

単一色相。値は primary ランプそのものになる。
**役割名を与えることが、この Issue の成果である。**
利用側はプリミティブを参照できないので（原則3）、
役割名が無いかぎり「連続値に使ってよい値」がそもそも存在しない。

## 回帰検査

`packages/tokens/test/sequential.test.ts` が、全36色相・二色覚3種・両モードで
単調性を検査する。**この実験で退けた多色相の帯を陰性対照として当てており、
検出器が発火することを毎回確かめてから本体を見る**（教訓2）。
