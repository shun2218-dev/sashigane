# 実験: 中性色の色相は primary から受け継ぐべきか

実施日: 2026-08-24
関連: [decisions.md 決定5-6](../decisions.md) / [Issue #33](https://github.com/shun2218-dev/sashigane/issues/33) /
[experiments/phase2-ichirizuka.md](./phase2-ichirizuka.md)

## なぜ実験したか

決定5-6 は「中間色は primary の色相で着色する」と決め、根拠にこう書いていた。

> 観測した4本の中間色は**すべて純グレーではなかった。**

Phase 2 で ichirizuka にトークンを導入したとき、中性色の色相が **−21〜−54° ずれた。**
teal（192.8°）のアクセントに青寄りのグレーを合わせている設計だったためである。

そのとき**穴4 として記録した。** しかし記録の時点で気づいていた問題がある。

> 決定5-6 の根拠（観測した4本の中間色はすべて純グレーではなかった）は、
> **「色が付いている」ことは示しているが「primary と同じ色相である」ことは示していない。**

根拠が結論を支えていない。確かめる。

## 方法1: 観測に戻る

観測対象4本（pylabo は light / dark で別テーマなので5組）について、
accent の色相と中性色の色相の差を測った。

## 結果1: 色相の一致を支持していたのは1本だけだった

| | accent | 中性色の ΔH |
|---|---|---|
| **pylabo (dark)** | #4f8cff 261.7° | **2.7 〜 9.9°** |
| **pylabo (light)** | #2563eb 262.9° | **−1.1 〜 12.1°** |
| ichirizuka | #1f7a78 192.8° | 4.4 〜 **54.1°** |
| holosphere | #e879f9 322.2° | **−26.4 〜 −38.2°** |
| pdf-merge-app | （shadcn 既定。accent も中性色） | 中性色は **C = 0**、色相なし |

**pylabo だけが支持していた。** 2テーマとも独立に支持しているので票としては強いが、
1人の設計者の1プロジェクトである。

ichirizuka と holosphere は**明確に反する。**
pdf-merge-app は無彩色で、[roles.md](../roles.md) が言うとおり本人の選択ではないので無効票。

**4本中1本。決定5-6 の根拠の記述は誤っていた。**

### 副産物: 中性色の色相は明度とともに動いていた

反していた2本には、どちらにも規則性があった。

```
ichirizuka   card(L .978) 197°  →  paper(.940) 214°  →  rule(.843) 220°
             →  faint(.709) 229°  →  muted(.552) 234°  →  ink(.238) 247°

holosphere   地(L .155) 283.9°  →  grad-mid(.200) 287.1°  →  grad-end(.218) 295.7°
```

**どちらも「明るい段ほど accent の色相に近い」。** 単調に動いている。
accent 色相から一定量ずらすのではなく、**明度に応じてドリフトさせている。**

pylabo にはこのドリフトが無い（ほぼ一定）。

## 方法2: その色相差は見えるのか

ここで止めれば「決定5-6 は観測に支持されていない。入力を増やすべきだ」となる。
**その前に、色相差が知覚できるのかを測る。**

実際の値と、**同じ L・C のまま色相だけを accent に合わせた値**の
OKLab 距離（決定5-8 と同じ尺度）を取った。

| 対象 | 実際の値 | accent 色相に置換 | ΔE | C |
|---|---|---|---|---|
| ichirizuka `--ink`（ΔH 54.1°） | #14202b | #0e2322 | **0.025** | 0.027 |
| ichirizuka `--muted` | #64757f | #617776 | 0.018 | 0.026 |
| ichirizuka `--rule` | #c2ced2 | #c2cfce | 0.007 | 0.014 |
| ichirizuka `--paper` | #e8eced | #e8ecec | 0.002 | 0.005 |
| holosphere 地（ΔH −38.2°） | #0b0b14 | #100911 | 0.013 | 0.019 |
| holosphere grad-end | #1e1038 | #290b2e | **0.034** | 0.074 |
| pylabo(dark) `--line` | #2a3040 | #283140 | 0.004 | 0.030 |
| pylabo(light) `--fg` | #1a1f2e | #18202e | 0.004 | 0.030 |

**すべて 0.034 以下。**

決定5-5 が識別可能の目標としている値は **0.08**（Okabe-Ito 5色の実測 0.086 が基準）。
参考までに、赤と緑の ΔE は 0.415 である。

**色相差 54° が、知覚上は 0.025 にしかならない。** 彩度が低いためである。

## 結果2: sashigane の中性色では、色相の選択は原理的に見えない

生成器の側でも測った。全360色相・全11段について、
**色相を最も遠い 180° へ振ったときの知覚差**を取る。

```
中性色の彩度の最大値                       C = 0.0289
色相を 180° ずらしたときの知覚差の最大     ΔE = 0.0578
```

**最悪ケースでも識別閾 0.08 に届かない。**

## 結論: 決定は維持する。根拠を差し替える

決定5-6 は正しい。**ただし理由が違った。**

| | |
|---|---|
| 当初の根拠 | 観測した4本の中間色がすべて純グレーではなかった → **観測は色相の一致を支持していない** |
| 実際の根拠 | **中性色の彩度が低いため、色相をどう選んでも知覚上区別できない** |

見えない差のために入力を増やさない。決定5-1（入力は primary 1色）を維持する。

### 前提が崩れる条件を検査にする

新しい根拠は**構造に依存している。** 中性色の彩度を上げる変更が入れば前提は崩れる。
観測ではなく構造が根拠なら、**構造の側を検査する。**

`packages/tokens/test/color.test.ts` に不変条件を2つ足した。

- 中性色は primary の色相を受け継ぐ（決定の規則そのもの）
- **色相をどう選んでも知覚上の差が識別閾に届かない**（決定が無害である条件）

`neutralRatio` を 0.2 から 0.8 に上げると後者が落ちることを確認した。

### Phase 2 の「穴4」は穴ではなかった

[phase2-ichirizuka.md](./phase2-ichirizuka.md) は
「中性色の色相を primary と独立に選べない」を穴として記録していた。

**測ると見えない差だった。** 記録を訂正する。

観測した色相差（−21〜−54°）は事実だが、**それが問題であるとは示していなかった。**
数値が大きいことと、それが知覚できることは別である。

## 残る限界

- **ドリフト（明度に応じて色相を動かす）を採らない判断は、この実験では決めていない。**
  ドリフトの有無も同じ理由で知覚できないため、複雑さを足す理由が無いというだけである
- 彩度の高い装飾グラデーション（holosphere の grad-end、C=0.074）は
  中性色ランプの範囲外にある。**その領域では色相の選択が見え始める**（ΔE 0.034）
