## 依存を1つ持ちます

**この系で唯一、外のライブラリに乗っている部品です**（`embla-carousel-react`）。

素の `scroll-snap` でも送りと吸着はできますが、**掴んで引く操作**と**端で折り返す送り**は
自分で書くことになります。どちらもサイトやアプリで普通に使われるものです。

**依存はこの部品を入れたときだけ増えます。** トークンだけ、あるいは他の部品だけを
入れた場合には付きません。

## 前後のボタンと印は自分で描いています

ブラウザが作ってくれる仕組み（`::scroll-button()` と `::scroll-marker`）は
**Chromium にしかありません。** 乗せると、他のブラウザで操作手段そのものが消えます。

## 名前が要ります

`label` は必須です。**何のカルーセルかが読み上げに出ない**と、
前後に送っても何を見ているのか分かりません。

```tsx
<Carousel label="おすすめ">
```

## 端では押せません

**送る先が無いのに押せるのは嘘です。** 1枚しか無ければ、前も次も押せません。

折り返す形（`loop`）は既定ではありません。**「最後まで来た」が分からなくなる**ので、
見せ物のときだけ入れてください。

## いまの場所は色以外でも分かります

印は `aria-current` を持ちます。**色だけで伝えると、見えない人に届きません。**

## ボタンと印は送り枠の外に置いてください

`CarouselSlides` が送り枠を描きます。**その外に置かないと一緒に送られ**、
2枚目へ進んだ瞬間に画面の外へ出ます。見た目には「ボタンが消えた」としか映りません。

## 動きを減らす設定では飛びます

送りの動きは止まり、すぐに切り替わります。**利用側で何かする必要はありません。**
