## 依存を1つ持ちます

**この系で唯一、外のライブラリに乗っている部品です**（`embla-carousel-react`）。

素の `scroll-snap` でも送りと吸着はできますが、**掴んで引く操作**と**端で折り返す送り**は
自分で書くことになります。どちらもサイトやアプリで普通に使われるものです。

**依存はこの部品を入れたときだけ増えます。** トークンだけ、あるいは他の部品だけを
入れた場合には付きません。

## 送りの設定はそのまま渡せます

`options` は **Embla の設定をそのまま受けます。** こちらで包み直していないので、
Embla が設定を足せば何もせずに使えます。

```tsx
<Carousel label="おすすめ" options={{ loop: true, align: 'start', slidesToScroll: 2 }}>
```

よく使うもの。

| | |
|---|---|
| `loop` | 端で折り返す。**順番に意味が無いときだけ**（下に条件があります） |
| `align` | 吸着の位置（`start` / `center` / `end`） |
| `slidesToScroll` | 1回で何枚送るか |
| `dragFree` | 吸着せずに慣性で流す |
| `startIndex` | 何枚目から始めるか |

全部の一覧は [Embla の設定](https://www.embla-carousel.com/api/options/)にあります。

**`duration` だけ渡せません。** 送りの速さは**動きを減らす設定から決めている**ので、
渡せるようにすると利用側がその設定を打ち消せてしまいます。
尊重するのは利用側の責務ではありません。

## 前後のボタンと印は自分で描いています

ブラウザが作ってくれる仕組み（`::scroll-button()` と `::scroll-marker`）は
**Chromium にしかありません。** 乗せると、他のブラウザで操作手段そのものが消えます。

## 名前が要ります

`label` は必須です。**何のカルーセルかが読み上げに出ない**と、
前後に送っても何を見ているのか分かりません。

```tsx
<Carousel label="おすすめ">
```

## 端では押せません

**送る先が無いのに押せるのは嘘です。** 1枚しか無ければ、前も次も押せません。

## 折り返しをいつ使うか

折り返す形（`options={{ loop: true }}`）は既定ではありません。

| | |
|---|---|
| **入れてよい** | 写真・広告・お客様の声のように、**順番に意味が無い**もの。どこから見ても構わない |
| **入れない** | 手順・記事の並び・検索結果のように、**順番に意味がある**もの |

折り返すと「最後まで来た」が分からなくなります。
**順番に意味があるものでは、終わりに着いたことが読み取れなくなります。**

## いまの場所は色以外でも分かります

印は `aria-current` を持ちます。**色だけで伝えると、見えない人に届きません。**

## ボタンと印は送り枠の外に置いてください

`CarouselSlides` が送り枠を描きます。**その外に置かないと一緒に送られ**、
2枚目へ進んだ瞬間に画面の外へ出ます。見た目には「ボタンが消えた」としか映りません。

## 自動で送るときは、止める器が必須です

`autoplay` を使うときは `CarouselPlayPause` を一緒に置いてください。
**置かないと落ちます。**

```tsx
<Carousel label="おすすめの写真" autoplay>
  <CarouselSlides>…</CarouselSlides>
  <CarouselPrevious />
  <CarouselNext />
  <CarouselMarkers />
  <CarouselPlayPause />
</Carousel>
```

## 4つの器は、それぞれ別の役目です

**止める器は、送る器の代わりではありません。**

| | 役目 |
|---|---|
| 前へ・次へ | **場所を移す** |
| 止める・再生 | **勝手に動くのを制する** |
| 印 | **いまどこか**を示す |

同じ場所に置くと片方が消えます。**実際に、止める器を「前へ」の場所に置いた例を配り、
前へ送る手段が消えていました。**

例が片方を落としたら落ちるように、いまはテストが見ています。

自動で動くものには**止める手段が無ければなりません**（WCAG 2.2.2）。
文書に書くだけでは守られないので、**組み立ての側で成立しない形**にしています。

**黙って動き続けるほうが害が大きい**——読んでいる最中に勝手に送られ、止める方法がありません。

間隔の既定は 4000ms です。**選んだ値で、段から導いてはいません。**`autoplay={{ delay: 8000 }}` のように渡せます。

触ったとき・ポインタが乗ったとき・焦点が入ったときは止まります。
**読んでいる最中に送られるのは邪魔です。**

**動きを減らす設定のときは、止まった状態で始まります。**
黙って動かしませんが、動かす手段は残します。
