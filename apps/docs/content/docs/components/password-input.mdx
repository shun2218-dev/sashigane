## `type` を入れ替えます

`type` は CSS では変えられません。**この部品は状態を持つ**ので、
サーバ側では描けません。

入れ替えるのは**同じ要素の属性だけ**です。器ごと差し替えると、
**打っている最中にフォーカスが外れて、以降の文字が入らなくなります。**
見た目には何も出ないので、打ち続けて初めて分かります。

テストが**打ちながら切り替えて**、続けて打った文字が入ることを測っています。

## 見た目は Input から借りています

線も箱も入力欄と同じものを使います。**写しを作ると、片方だけ直したときにずれます。**

## 札が状態を伝えます

ボタンの札が「パスワードを表示」から「パスワードを隠す」に変わります。
**目の図案だけでは、いまどちらなのかが読み上げに出ません。**

札は差し替えられます。

```tsx
<PasswordInput showLabel="Show password" hideLabel="Hide password" />
```

## 満たしている印と場所を分けます

Field は満たしているとき、印を欄の末尾に重ねます。**切り替えのボタンも末尾にあります。**
そのままだと重なるので、満たしているときだけボタンを内側へ寄せています。

寄せ幅は印の位置から決まります。**当てずっぽうではありません**——
印は末尾から 12px の位置に 16px で置かれるので、末尾から 28px までを占めます。
24px では 4px 重なりました。

## 切り替えはフォームを送りません

ボタンの既定の `type` は `submit` です。**そのままだと、見せようとした瞬間に送信されます。**

## 押せないときは切り替えも押せません

**中身が見えないのに切り替えだけ動くのは嘘です。**

## 値は覚えません

この部品が覚えるのは「**見せているかどうか**」だけです。値は利用側が持ちます。

`autoComplete` は利用側が渡してください。ログインなら `current-password`、
登録なら `new-password` です。**こちらで決めると、片方が必ず間違いになります。**
