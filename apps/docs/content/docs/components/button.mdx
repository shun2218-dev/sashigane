決定6-1 の2番目。**Button は、決定が Phase 3 送りにした論点を2つ解いた。**

## 押下（`:active`）は表現しない

決定5-13 は押下の表現を保留し、「**Phase 3 でコンポーネントを書いてから決める**」と書いた。

Phase 3 で観測を測ったところ、**`:active` を使っている自作コードは4本とも0件**だった。
`roles.md` の `bg-active`（i p h）は**選択状態**の誤記録で、
pylabo は `bg-inset`、holosphere は淡い塗りで書いている——**どちらも既存の役割**である。

**原則7 に従い持たない。**

## 無効は面を沈めて表す

不透明度は持たない（決定1-15）。無効のときだけ **`inset` の面を宣言し、
文字を `text-faint` にする。** 新しい役割は足していない。

面の仕掛け（決定5-12）に乗るので、**塗り・淡い塗り・枠・文字だけのどれでも同じ形で沈む。**
塗りが残って「押せそうに見えて押せない」状態にならない。

## 色は1つも決めていない

塗りと `on-*` は決定5-14、hover の1段ずらしは決定5-15、淡い塗りは決定5-16 が既に決めている。
ランプは**塗りを持つものすべて**に出す（決定5-15 改訂）。
