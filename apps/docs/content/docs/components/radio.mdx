## グループのラベルが要ります

1つずつのラベル（「ふつう」「大きい」）だけでは、
**何についての選択なのかが読み上げに出ません。**

グループのラベルは `fieldset` と `legend` でしか作れません。`div` に `aria-label` を足す形も
動きますが、**`legend` は選択肢を読むたびにグループのラベルを添えます。**

```tsx
<RadioGroup id="plan" label="プラン">
  <Field layout="inline" id="plan-a" label="ふつう">
    <Radio name="plan" value="a" />
  </Field>
  <Field layout="inline" id="plan-b" label="大きい">
    <Radio name="plan" value="b" />
  </Field>
</RadioGroup>
```

## name は利用側が渡します

グループから配っていません。配るには文脈（context）が要り、
**この部品がクライアント側になります。** いまはどの部品もサーバ側で描けます。

`name` が揃っていないと、**全部が独立に選べる状態になります。**
これはテストが測っています。

## 誤りはグループに付きます

選ばれていないのは選択肢1つの問題ではないので、1つずつに赤い線を引いても
**どれを直せばよいか伝わりません。**
