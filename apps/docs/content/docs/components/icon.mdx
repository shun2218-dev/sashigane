## 図案は選んでいます

**lucide** の図案を使います。実行時の依存を持たず、必要なものだけが束に入ります。

このシステムが持つのは**寸法・読み上げの既定・名乗り**だけです。図案そのものは lucide のものです。

## `lucide-react` は一緒に入ります

Icon を入れると `lucide-react` も入ります。**別途インストールする必要はありません。**

ただし**ここに無い図案を足すときは、利用側が `lucide-react` から import します**——
図案そのものは lucide のものだからです。

## ここに無い図案は、同じ形で足せます

包む形を公開しています。**全部を持たない代わりに、足す道を配ります。**

```tsx
import { Search } from 'lucide-react';
import { defineIcon } from '@sashigane/ui';

export const IconSearch = defineIcon(Search);
```

props は lucide のものをそのまま引き継ぎます。

**名乗りは図案の名前から導きます。** `Search` なら `icon-search`、
`ChevronDown` なら `icon-chevron-down` です。**手で書きません**——
書くと2箇所に同じことが並び、片方だけ直したときに静かにずれます。

## 既定は読み上げから隠れます

アイコンはたいてい**文字の隣にあり、同じことを言っています。**
隠さないと二重に読まれます。

名前を渡したときだけ隠れません。

```tsx
<IconX />                    {/* 飾り。読み上げに出ません */}
<IconX aria-label="閉じる" /> {/* アイコンだけで意味を伝える場所 */}
```

## 大きさは段で選びます

| 段 | 使うところ |
|---|---|
| `sm` | 札や表の行の中 |
| `md`（既定） | 文字やボタンと並べるとき。**行の高さと同じ** |

**`className` で大きさは上書きできません。** 同じ次元を上書きしたとき、
どちらが効くかをこのシステムは保証していないためです——
実際 `size-4` を渡しても既定に負けます。**段にすれば、負ける形が生まれません。**

## `size` は通していません

lucide は `width` / `height` の**属性**で書きますが、こちらはクラスで書きます。
**CSS は属性に勝つ**ので、`size` を渡しても**何も起きないまま消えます。**
