## 依存は持ちません

素の HTML にタブはありませんが、**作るのに要るのはブラウザが持っているものだけ**です——
`button` と、焦点の移動と、鍵盤の催し。

## 焦点が入るのは1つだけです

選ばれているものだけが Tab キーの順に入ります。**全部入ると、
タブの数だけ Tab キーを押すことになります。**

並びの中は矢印で移ります。`Home` で先頭、`End` で末尾。
**端では折り返します**——端から端へ戻るのに全部通らずに済みます。

## 矢印で移った先は、すぐ開きます

`activation="manual"` を渡すと、**押して初めて開きます。**

| | いつ |
|---|---|
| `automatic`（既定） | **中身がその場にある**とき。開くのに待ちがない |
| `manual` | **中身の読み込みに時間がかかる**とき。すぐ開く形だと、矢印で通り過ぎるだけで毎回読み込むことになる |

## 押せないタブは飛ばされます

矢印で止まりません。**止まれるのに開けないのは嘘です。**

## 名前は利用側が渡します

`id` から `aria-controls` と `aria-labelledby` を作ります。
**同じ画面に2つ置くときは別の名前を渡してください。**

器が作って配る形にはしていません。**利用側が中身を別の場所から指したいとき**に
名前が分からなくなるためです。

## 中身は先に描かれます

選ばれていないものも DOM にあります（隠れているだけ）。
**検索で見つかり、印刷にも出ます。**

描かないようにしたいときは、**利用側が中身の側で決めてください。**
