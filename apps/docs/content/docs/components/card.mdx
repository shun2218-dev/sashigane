決定6-1 の1番目。**面の宣言（`data-sg-surface`）の使い方を決めるコンポーネント。**

## 面は塗らずに宣言する

原則5 は「**面は `data-sg-surface` で宣言する。塗るだけの方法は用意しない**」と決めている。
塗れてしまうと**前景がページ用のまま残り、コントラスト保証が崩れてもエラーにならない**。

そのため Card は `bg-*` を1つも書かない。背景も文字色も境界色も、面の宣言から来る。

```tsx
<Card>内容</Card>
```

## hover も塗らない

`interactive` は `data-sg-interactive` を付けるだけである。
背景だけを1段深くすると前景が置き去りになるので、**塗る道は用意していない。**

## overlay は浮きが要る

`overlay` は `surface` と**同じ段**に置いてある。そのため浮きが無いと暗色で下地と同化する。
**`surface="overlay"` を選ぶと浮きが自動で付く**——「付けられる」ではなく
「無しでは組み立てられない」形にしてある。
