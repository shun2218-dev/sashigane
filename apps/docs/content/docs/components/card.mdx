面の宣言（`data-sg-surface`）の使い方を決めるコンポーネントです。

## 面は塗らずに宣言する

Card は背景色を1つも書きません。背景も文字色も境界色も、面の宣言から来ます。

```tsx
<Card>内容</Card>
```

背景だけを塗る方法を用意していないのは、**塗れてしまうと前景が親の面のまま残り、
読みにくい組み合わせができてもエラーにならない**ためです。

## hover も塗らない

`interactive` は面の文脈を1段深くするだけで、背景を直接塗りません。
背景だけを深くすると前景が置き去りになるので、塗る道は用意していません。

## overlay は浮きが要る

`overlay` は通常の面と**同じ深さ**に置いてあります。そのため浮きが無いと暗色で下地と同化します。

**`surface="overlay"` を選ぶと浮きが自動で付きます**——「付けられる」ではなく
「無しでは組み立てられない」形にしてあります。

## 中のセクション

見出しと操作はセクションで分けます。**セクションは面も色も持ちません**——
面を宣言するのは枠だけです。

```tsx
<Card>
  <CardHeader>
    <CardTitle>見出し</CardTitle>
    <CardDescription>補足</CardDescription>
  </CardHeader>
  <p>本文</p>
  <CardFooter>
    <Button>進む</Button>
  </CardFooter>
</Card>
```

セクションは**必須ではありません。** 要るセクションだけ置けば足ります。
枠は中身を縦に並べて間を空けるだけなので、セクションを使わずに直接書いても崩れません。

### 本文のセクションはありません

**本文は枠の直下に置きます。** 一度 `CardBody` を用意しましたが、
クラスを1つも持たない `div` でした——書かなくても崩れず、書いても何も起きません。
枠が縦に並べて間を空けるので、それで足ります。

### 見出しの深さは決め打ちしていません

`CardTitle` は既定で `h3` になります。**カードがページのどこに置かれるかで正しい深さは変わる**
ので、`asChild` で差し替えられます。

```tsx
<CardTitle asChild>
  <h2>ページ直下に置くとき</h2>
</CardTitle>
```

### 操作は下端に寄ります

`CardFooter` は下端に寄ります。高さの揃った並びに置いたとき、
**カードごとに本文の長さが違っても操作の位置が揃います。**

### 画像のセクションは持っていません

画像はそのまま中身として置けます。**枠の余白いっぱいまで広げる**セクションは用意していません——
広げ方（縦横比、角の丸め、上端だけか両端か）を決めていないためです。
決めずに口だけ用意すると、**利用側ごとに違う広げ方が生まれます。**

## 枠が `div` とは限りません

記事なら `article`、セクションなら `section`、カード全体がリンクなら `a` になります。
`asChild` を付けると、**この枠は要素を1つも作らず**、クラスと属性を子へ移して子だけを描きます。

```tsx
<Card asChild>
  <article>
    <h3>見出し</h3>
    <p>本文</p>
  </article>
</Card>
```

**面の宣言も hover の宣言もそのまま子へ移ります。**
リンクになっても、背景と前景は同時に切り替わります。

子は**要素1つだけ**です。
