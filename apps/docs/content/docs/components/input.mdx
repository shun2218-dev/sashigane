## 凹んだ面を宣言します

入力欄は**地**であって塗りではありません。面の仕組みに乗るので、
背景と文字が対で決まります。**塗るだけの道はありません。**

## 誤りは自分で決めません

`aria-invalid` が付くと境界が変わります。**付けるのは Field です**——
ここで決めると、Field を使わない書き方だけが誤りを名乗れることになります。

境界の色は `border-danger-mark` です。`border-danger` は**生成されません**——
境界に使えるランプの色は mark だけで、これは**文字ではないものに要る 3:1 を満たす段**なので、
役割としても合っています。

**境界だけで伝えません。** Field が文言も一緒に出します。

## 押せないときは文字が淡くなります

**不透明度では表しません。** 薄めると前景と背景が同時に下地へ寄り、
読みやすさの保証が効かなくなります。
