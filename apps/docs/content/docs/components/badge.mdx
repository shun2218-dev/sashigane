## 色は宣言から来ます

**中立は凹んだ面を宣言します。** 色付きは**淡い塗り**を使います。
どちらも背景と文字が対で決まっているので、**背景だけを塗る道はありません。**

```tsx
<Badge>中立</Badge>
<Badge tone="danger">危険</Badge>
```

ランプは塗りを持つものすべて（`accent` / `danger` / `warning` / `success` / `info`）に加えて、
色を持たない `neutral` があります。**既定は `neutral` です。**

## 境界を持ちます

**凹んだ面の上に置くと、中立の札は背景と同じ色になります。**
面の段は凹んだところで底に着くので、その上に凹んだ面を宣言しても深くなりません。

境界があれば、背景が同じでも札の輪郭が読めます。

## 押せるものではありません

hover も focus も持ちません。**押せるようにしたいなら Button を使ってください。**

リンクにしたいときは `asChild` で `a` を渡せます。**そのときも見た目は変わりません**——
押せることが見た目から分からないので、押す前提の導線には向きません。

```tsx
<Badge asChild>
  <a href="/tags/x">タグへ</a>
</Badge>
```

## 大きさは2段です

小さい方は表の行や見出しの脇に、大きい方は本文と並べて使います。

## 折り返しません

札は1行に収まる前提です。**長い語は器の側で切るか、そもそも短い語だけを載せてください。**
