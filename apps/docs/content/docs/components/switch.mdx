## チェックボックスとの違い

**押した瞬間に効くもの**がスイッチです。
チェックボックスは**送信して初めて効きます。**

見た目だけの違いではないので、部品を分けています。
迷ったときは「押したら何か起きるか」で決めてください。

## 素の input に乗っています

`type="checkbox"` に `role="switch"` を足しただけです。
**入ったかどうかの申告も、鍵盤も、フォームへの載り方もブラウザが持っています。**

自分で状態を持っていないので、素のフォームでも `register()` でもそのまま載ります。

## つまみは境界で形を保ちます

つまみは、**入っているときアクセントの塗りの上、切れているとき凹んだ面の上**に載ります。
地の色が両極なので、**塗りだけでは片方で沈みます。**

境界が識別を担っています。

## ラベルは Field が付けます

何の入り切りかは、スイッチ自身からは分かりません。

```tsx
<Field layout="inline" id="dark" label="暗い配色にする">
  <Switch name="dark" />
</Field>
```

## 押せないときは塗りの段が落ちます

**不透明度では表しません。** 薄めると前景と背景が同時に下地へ寄り、
読みやすさの保証が効かなくなります。
