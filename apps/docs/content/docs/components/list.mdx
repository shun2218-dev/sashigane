## 印は既定で出しません

素の `ul` の点や数字は初期化で消えます。**戻すのは選んだときだけ**にしています——
並べたものが文章とは限らないためです（札の一覧、設定の行）。

```tsx
<List>…</List>                      {/* 印なし */}
<List marker="bullet">…</List>      {/* 点 */}
<List ordered marker="number">…</List>  {/* 数字 */}
```

## 順序は意味です

`ordered` を付けると `ol` になります。**見た目ではなく意味**で、
読み上げが順序を伝えられるようになります。

**数字に見えるだけでは足りません。** `marker="number"` は見た目、`ordered` は意味です。
順序のある並びには両方付けてください。

## 区切り線は升が持ちます

**最初の升だけ線を持ちません。** 上端に線が残ると、器の枠に見えるためです。

線を選ぶと**升の間隔は詰まります**——線が間隔を担うので、二重に空けません。

```tsx
<List separated>
  <ListItem separated>設定の行</ListItem>
  <ListItem separated>線で区切られています</ListItem>
</List>
```

### 器から升へは自動で降りません

`separated` は器と升の両方に書きます。**`li` は器の直下とは限らず**、
間に何かを挟んだときに静かにずれるためです。

## 升の中は自由です

`ListItem` は `li` を作るだけです。リンクにしたいときは**中にリンクを置いてください**——
`li` そのものを差し替えると、並びの意味が壊れます。
