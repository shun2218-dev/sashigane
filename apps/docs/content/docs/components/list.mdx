## 行頭の記号は既定で出しません

素の `ul` の点や数字は初期化で消えます。**戻すのは選んだときだけ**にしています——
並べたものが文章とは限らないためです（ラベルの一覧、設定の行）。

```tsx
<List>…</List>                      {/* 記号なし */}
<List marker="bullet">…</List>      {/* 点 */}
<List ordered marker="number">…</List>  {/* 数字 */}
```

## 順序があるリストには `ordered` を付けてください

`ordered` を付けると `ol` になります。**見た目ではなくマークアップが変わる**ので、
読み上げが「1番目の項目」のように順序を伝えられるようになります。

**数字が見えているだけでは足りません。** `marker="number"` は見た目だけを変え、
`ordered` はマークアップを変えます。順序のあるリストには**両方**付けてください。

## 区切り線は各項目の上辺に引かれます

**先頭の項目だけ線が付きません。** リストの上端に線が残ると、外側に枠があるように
見えてしまうためです。

線を付けると**項目どうしの余白は詰まります**——線が区切りの役目を担うので、
余白と二重にしません。

```tsx
<List separated>
  <ListItem separated>設定の行</ListItem>
  <ListItem separated>線で区切られています</ListItem>
</List>
```

### 枠から項目へは自動で降りません

`separated` は枠と項目の両方に書きます。**`li` は枠の直下とは限らず**、
間に何かを挟んだときに静かにずれるためです。

## 項目の中は自由です

`ListItem` は `li` を作るだけです。リンクにしたいときは**中にリンクを置いてください**——
`li` そのものを差し替えると、並びの意味が壊れます。
