`tokens.json` を単一のソースとし、CSS 変数・TS 型・Tailwind アダプタを生成する。
**値は規則から導き、既存プロジェクトから抽出しない。**

## 導入の深さは3段階ある

| 深度 | 内容 |
|---|---|
| `@sashigane/tokens` | CSS 変数のみ。React 非依存 |
| `@sashigane/<component>` | コンポーネント単体 |
| `@sashigane/base` | 全部 |

**トークンのみのインストールが実際に動くことが、層分離の証明になる。**

## コンポーネントは順に足している

いまあるのは **Card と Button の2つ**で、続きは Badge → Separator → Table と決めてある。
**「あった方が良さそう」では追加しない。**

## 設計の記録

このリポジトリは AI 駆動開発の実践例を兼ねている。
**設計判断の根拠と、失敗の記録が成果物の一部である。**
決定の全文・退けた案・改訂履歴はリポジトリの `docs/` にある。
