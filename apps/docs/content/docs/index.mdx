sashigane は、**CSS 変数の一式**と、その上に立つ **React のコンポーネント**です。

npm のパッケージではなく、`shadcn` の CLI で**コードが手元のリポジトリに落ちます。**
落ちたものは自分のコードなので、好きに変えられます。

## すぐ試す

```bash
npx shadcn@latest add @sashigane/button
```

配信元を `components.json` に1度書く必要があります。手順は
[導入する](/docs/install) にあります。

## 何が手に入るか

### 色を選ばなくても読める

色は OKLCH で作ってあり、明度の段が揃っています。**役割の名前で書けば、
明色でも暗色でも読める組み合わせになります。**

面の深さは `data-sg-surface` で宣言します。宣言すると、**背景と前景が一緒に**
深くなります。

```html
<body data-sg-surface="page">
  <article data-sg-surface="surface">…</article>
</body>
```

背景だけを塗る方法は用意していません。塗れてしまうと前景が浅いまま残り、
**読みにくい組み合わせができても何も起きない**からです。

### 寸法も名前で書ける

余白・字の大きさ・角丸・影は、`root = 16px` を基点に**1つの規則から作られています。**
値を選ぶ場面がないので、別々に作った画面でも寸法が揃います。

### React が要らない使い方もできる

トークンだけを落とせば、**素の CSS で使えます。** 面の宣言・塗り・覆い・
スケルトンの動きまで CSS に入っているので、React 以外でも動きます。

```bash
npx shadcn@latest add @sashigane/tokens
```

### 部品は自分の名前を名乗る

すべての部品が `data-sg-component` で自分の名前を出します。**見た目は持ちません。**

```html
<button data-sg-component="button" class="…">
<div data-sg-component="card" data-sg-surface="surface" class="…">
```

組み立てられたクラス名に頼らずに、**CSS からもテストからも部品を狙えます。**

```css
[data-sg-component="card"] { /* … */ }
```

`asChild` で要素を差し替えても**名乗りは子へ移ります**。枠が変わっても、
何であるかは変わりません。
