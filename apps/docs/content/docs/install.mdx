title: 導入する
description: 3つの深さから選ぶ。トークンだけでも動く
---

npm のパッケージではなく、**コードが手元のリポジトリに落ちます。**
落ちたものは自分のコードなので、好きに変えられます。

## まず配信元を1度書きます

`components.json` に `@sashigane` の在り処を書いてください。

```json
{
  "registries": {
    "@sashigane": "https://<配信先>/r/{name}.json"
  }
}
```

**これが無いと動きません。** 名前空間を付けずに `slot` などと書くと、
CLI は**shadcn 自身のレジストリ**を探しに行きます。

## 3つの深さ

| 深さ | 入るもの |
|---|---|
| トークンだけ | CSS 変数と面の仕組み。**React は要りません** |
| 部品ひとつ | その部品と、必要な共有物だけ |
| 全部 | トークンと部品の全部 |

```bash
# トークンだけ
npx shadcn@latest add @sashigane/tokens

# 部品ひとつ（必要な共有物は一緒に来ます）
npx shadcn@latest add @sashigane/button

# 全部
npx shadcn@latest add @sashigane/base
```

## 落ちる場所

| 種類 | 落ちる先 |
|---|---|
| 部品 | `components/ui/` |
| 共有物（`slot` / `ring`） | `lib/` |
| トークンの CSS | `styles/` |

部品の中の参照は `@/components/ui/...` と `@/lib/...` に書き換わって落ちます。

必要な npm の依存（`class-variance-authority` / `lucide-react`）は、
CLI が一緒に入れます。

## トークンだけでも動きます

トークンは**変数だけではありません。** 面の宣言（`data-sg-surface`）・塗り・覆い・
骨組み表示の動きも入っています。React に依存しないので、
**素の CSS でも、他のフレームワークでも使えます。**

落としたら読み込んでください。

```css
@import './styles/sashigane-tokens.css';
```

Tailwind から役割名（`text-body` `bg-accent-subtle` `max-w-32rem` など）を
使いたいときは、アダプタも読み込みます。

```css
@import './styles/sashigane-theme.css';
```

## 落ちた先で成立することを検査しています

**1件ずつ落としたときに参照先が揃っていること**と、
**全部落とした木がそのままコンパイルできること**を、毎回確かめています。

前者が要ります——全部まとめて確かめるだけだと、
**必要な共有物の書き漏れが、他の部品が持ってきたファイルで隠れます。**

CLI で実際に落として確かめるのは、**配信先の URL が要るので手元で行います。**
3つの深さすべてを落とし、置かれた木がコンパイルできることを確認しています。
