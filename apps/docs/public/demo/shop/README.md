# デモの画像

コンポーネントを使ったデモ（`/demo/shop`）が使う写真。

## 追跡しているのは WebP だけ

元の JPEG は1枚 3MB あり、15枚で 42MB だった。**そのまま置く理由が無い。**
幅を抑えて WebP にすると 1.4MB になる（30分の1）。

**元の JPEG は追跡していない。** 作り直すときは生成からやり直す——
生成の指示は `docs/experiments/` ではなくこの会話にしか無いので、
**必要になったら書き起こすこと。**

## 変換の手順

新しい写真を足すときは、JPEG をここへ置いてから次を実行する。

```bash
pnpm dlx sharp-cli --input <file>.jpg --output . -f webp -q 78 resize <幅>
```

幅は用途で決める。

| 用途 | 幅 |
|---|---|
| 商品（4:3） | 1200 |
| 案内スライド（16:9） | 1600 |
| 案内スライドの縦長版（`-sp`） | 900 |

**`sharp` は常用の依存に入れていない。** 写真を足すのは稀なので、
そのときだけ `pnpm dlx` で呼ぶ。

## 名前の決まり

商品は `data.ts` の `slug` と一致させる。**一致しないと繋がらない。**
